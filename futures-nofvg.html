📖 What this is

The exact same TFW strategy — EMA-21 pullback + A++ wick, NO Fair-Value-Gap filter — run on real exchange futures contracts (CME, COMEX, NYMEX, CBOT, ICE) in TradingView, sized the way a real futures account works.

🔧 How it's sized (realistic futures)

  • $100,000 account, 3% risk per trade. Each trade risks 3% of the current balance (compounding).
  • Whole contracts at the real point value. The number of contracts = how many whole contracts ≈ 3% risk (ES = $50/pt, GC = $100/oz, CL = $1,000/bbl, …). You can't trade a fraction of a contract, so size is rounded down.
  • Real costs: ~$4 per-contract round-turn commission + 1-tick slippage.
  • Why this matters: futures are large, so risk-based sizing is essential — a naive "1 contract every trade" blows the account, while risk-sizing preserves the edge.

📊 How to read it

Each contract shows profit factor (money won ÷ money lost) across four windows — 5 years, 2 years, 1 year, 6 months — with the number of trades in that window underneath. Above 1.3 = strong, 1.0–1.3 = profitable, below 1.0 = lost money. Green across all windows = a durable edge; strong only in the 5-year column = possibly fading. The $ columns are the net return and final balance on the $100k account after commissions.

⚠️ Honest caveats

  • † Grain & coffee dollars are not shown. CBOT corn/wheat/soybeans and ICE coffee are cents-quoted; TradingView mis-reports their contract point value on the continuous series, so the dollar P&L is unreliable (off ~100×). Their profit factor and trade counts are valid and shown — the $ columns are not.
  • Continuous contracts. These use TradingView's 1! front-month continuous series, which stitch contracts at rollover; un-adjusted rollover gaps can occasionally create a signal a single contract wouldn't have.
  • Short windows are noisy. The 6-month and 1-year profit factors rest on a handful of trades — weight the longer windows.
  • Account size matters. Results are for a $100k account at 3% risk; a smaller account would need micro contracts (MES, MGC…).
  • Diagnostic only — for understanding the strategy on futures, not a signal to trade.

📚 Glossary

Profit factor = gross winnings ÷ gross losses. Point value = dollars per 1-point move of one contract. Whole-contract / risk-based sizing = buying the number of contracts whose stop-loss distance ≈ 3% of the account. Continuous (1!) contract = the rolling front-month series TradingView stitches together. Max ctr = the most contracts held at once. Win rate low is normal with a 1.5× reward:risk.

Method: EMA-21 daily retest + A++ wick (30%), NO FVG filter (retest + wick only), pending-stop entry, 1.5× target, risk-based whole-contract sizing at 3%/trade on $100k, real point value + ~$4/contract commission + 1-tick slippage. Engine C = TradingView. 5y window 2021-05-21 → 2026-05-20; sub-windows end 2026-05-20.
